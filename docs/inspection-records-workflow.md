# 巡查记录：开发过程与网页验收

日期：2026-11-05。业务数据均为合成数据。

## 业务含义

计划要求与执行声称、巡查观察分别保存。一条巡查对应一个明确点位；
点位或观察时间未知时保留 null。观察结果不直接等于计划完成或人员责任。
明确点位仅从当前计划单选，不自动展开地点层级或填入全部计划范围。
inspector_name 当前保存填报文字，人员认证尚未接入。

## 提交与恢复

先将 request_id 和 payload 写入当前标签页的 sessionStorage，再发送 POST。
pending 状态保留原编号和原内容，刷新后恢复；重试不重新读取表单构造请求。
422 明确拒绝后允许修正，沿用原编号；409 冲突后停止编辑与继续发送。
200/201 回执需与原提交编号、计划、人员、描述、观察结果、点位及观察时刻匹配。
只有点击“录入下一条巡查记录”后才清理该计划当前提交，下一次生成新编号。
关闭标签页后的草稿恢复尚未实现。
