## 地点归属与计划覆盖

Location.parent_id表示地点归属；PlanLocation.location_id表示计划明确选中的地点。
给大堂补父地点，不会新增或修改plan_locations的覆盖记录。
计划只选某间房时，不能据此认定覆盖整个单元、楼栋或分区。
后续查询到相关记录，也不等于证明整栋已完成工作或供水正常。

## 层级规则与地址

- community和unknown为根节点，不填父地点。
- area的父地点为community。
- building的父地点为community或area。
- unit的父地点为building。
- room的父地点为building或unit。
- public_space的父地点为community、area、building或unit。
- 重复编号、缺失父节点、自环及多节点循环均拒绝。

这些是本原型的业务契约。归属来自明确记录，不从中文名称或ID字符串猜测。
旧未分类点位可继续作为unknown根节点显示。
网页以display_path提供可读地址，以稳定ID提交和保存关系。
详情注明当前台账；目前没有事发时地址快照功能。
