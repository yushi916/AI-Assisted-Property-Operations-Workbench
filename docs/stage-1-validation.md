日期：2026-10-29。数据均为合成演示，不代表真实物业生产验证。

## 已验证功能

- 网页录入、保存回执、列表分页、详情查询和页面间跳转。
- 地点名称选择、稳定编号保存；未知地点不被自动关联。
- 描述原文保留，观察时间与接收时间分开。
- 空白输入拒绝；明确校验失败后允许修正。
- 同一提交编号同内容重试返回原记录，不同内容返回409。
- 地点初始化可重复执行，保留既有地点、版本和报事。
- Windows本机41项Python自动回归通过。
- Windows浏览器人工验收通过；浏览器端到端测试尚未进入CI。

41项组成：5输入 + 8数据库 + 20报事接口 + 1页面连接 + 7地点台账。

在保留的页面提交，记录提交编号；重启服务，在同一标签页刷新并原样重试；
核对提交编号不变、回执内容保留，再按该提交编号只读统计数据库行数为1。
重新运行会生成新的测试编号，不要求与上表相同。
