在已激活property-v2且已配置密钥的Windows CMD、项目根目录执行：

```bat
set GEMINI_MODEL=gemini-3.5-flash-lite
python evaluate_challenge_round.py run
```

run先自动验证冻结文件、关键代码、SDK、模型及密钥。缺密钥、模型不同或hash不同，都会在发请求前停止。不要发送密钥；配置不一致时把错误文字发回核对，不改hash绕过。仅离线核对可执行 `python evaluate_challenge_round.py verify`，不发请求。已冻结，不需要再次prepare。

## 逐条评审与收尾标准

程序取证、输出结构、内容评审分开。结构通过只说明字段、引用键、候选覆盖等约束通过，不能说明引用真的支持正文。
